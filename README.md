# LibManager

Aplicação de consola em *Python* para a gestão de uma biblioteca.

## Funcionalidades

- **Bibliotecário:** gere livros, sócios e empréstimos, controla atrasos e multas e aprova pedidos de renovação.
- **Sócio:** pesquisa livros, consulta os seus empréstimos e multas, pede renovações e faz reservas.

## Requisitos

*Python* 3.10 ou superior. Não é preciso instalar mais nada.

## Utilização

```bash
python main.py
```

No primeiro arranque é criada a base de dados `libmanager.db`. O bibliotecário por defeito é o número `1`, com a palavra-passe `admin`.
